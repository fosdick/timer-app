# 1.2.0 — release notes

Draft for App Store Connect "What's New". Three lengths; pick one and edit.
Apple's field allows 4000 characters, but almost nobody scrolls — the short
version is the one most people will actually read.

---

## Short (recommended)

```
Make it yours.

Six colour themes — Green, Leaf, Golden Sun, Tide, Ice and Dusk. Pick one in
User Preferences; the whole app follows.

The breath visual is now a ten-petal lotus that opens as you inhale and closes
```

## Long (only if you want the detail public)

```
Make it yours.

This release is about the app feeling like yours rather than like a tool you
borrowed.

COLOUR THEMES
Six of them: Green, Leaf, Golden Sun, Tide, Ice and Dusk. Choose one in User
Preferences and it carries across all three tabs. Green remains the default, so
nothing changes unless you want it to. Each theme is tuned to sit at the same
brightness as the others, so switching changes the temperature of the app
without making it louder or dimmer.

THE LOTUS
The breathing circle is now a ten-petal lotus — ten because that is how Manipura,
the solar-plexus chakra, is traditionally drawn. It opens across the inhale,
holds through a retention, and closes across the exhale.

CONTRAST AND HIERARCHY
The phase name and the selected pattern are now high contrast against the dark
background, so you can read them at a glance without breaking your rhythm. The
Pranayama controls are shaped by importance: patterns, counts and sounds each
read as their own kind of thing.

PRONOUNS
The account icon can be she, they or he — they by default. Its colour is fixed
and does not follow the theme.

FIXES
- The account button no longer sits on a grey system pill, and is no longer
  clipped at the bottom
- Opening User Preferences several times no longer requires several taps of the
  back arrow to return to your practice
- The "Begin in countdown" picker now follows your chosen colour instead of
  staying green
- Sounds no longer overlap at the very end of a Pranayama session
- Per-pattern session lengths are remembered correctly
```
